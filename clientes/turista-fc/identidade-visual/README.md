# Turista FC — Identidade Visual

Repositório oficial dos assets de marca da **Turista FC**.

---

## Estrutura

```
identidade-visual/
├── logo/
│   ├── logo-principal.png          # Logo principal
│   ├── logo-fundo-azul.png         # Versão fundo azul (uso preferencial)

│   └── logo-branca-transparente.png # Versão branca (fundos escuros)
├── fontes/
│   ├── Special_Gothic_Expanded_One/  # Arquivos de fonte
│   └── Special_Gothic_Expanded_One.zip
└── manual/
    └── manual-de-marca-turista-fc.pdf
```
