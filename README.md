# Squad Library

Biblioteca de squads de agentes de IA reutilizáveis. Cada squad é um time especializado pronto para ser ativado em projetos.

## Squads disponíveis

| Squad | Uso | Status |
|-------|-----|--------|
| [marketing/](squad/marketing/) | Conteúdo, redes sociais, campanhas para clientes | ✅ Pronto |
| [tech/](squad/tech/) | Desenvolvimento de apps e produtos digitais (Lean Startup) | ✅ Pronto |
| [comercial/](squad/comercial/) | Prospecção, proposta, fechamento | 🔜 Em breve |
| [criativo/](squad/criativo/) | Branding, identidade visual, design | 🔜 Em breve |

## Como usar

1. Escolha o squad certo para o tipo de projeto
2. Abra a pasta do squad e leia o `README.md`
3. Ative os agentes conforme o fluxo indicado
4. Um projeto pode combinar mais de um squad (ex: lançamento de marca = `criativo` + `marketing`)

## Composição de squads

```
Lançamento de produto digital   →   tech + marketing
Nova identidade visual          →   criativo + marketing
Prospecção + proposta           →   comercial
Campanha para cliente           →   marketing
```
