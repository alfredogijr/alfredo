# Advisory Board — Conselho dos Maiores Pensadores

Consulte os maiores pensadores da humanidade como conselheiros pessoais.

## Como usar

No Claude Code, digite:

```
/advisory-board [sua pergunta ou assunto]
```

### Exemplos

```
/advisory-board Devo expandir meu negócio para outro país?
/advisory-board listar
/advisory-board Einstein: como pensar em problemas complexos?
/advisory-board debate Maquiavel vs Gandhi: como lidar com oposição?
/advisory-board filósofos: o que é uma vida bem vivida?
```

## Categorias do Board

| Categoria | Conselheiros |
|-----------|-------------|
| Ciência & Invenção | Einstein, Newton, Tesla, Curie, Darwin, Feynman, Hawking, da Vinci... |
| Filosofia & Ética | Aristóteles, Sócrates, Kant, Nietzsche, Descartes, Popper, Arendt... |
| Estratégia & Liderança | Sun Tzu, Maquiavel, Napoleão, César, Churchill, Gandhi, Mandela... |
| Negócios & Economia | Drucker, Buffett, Munger, Jobs, Musk, Bezos, Dalio, Naval, Taleb... |
| Psicologia & Comportamento | Freud, Jung, Maslow, Kahneman, Frankl... |
| Tecnologia & Inovação | Turing, Von Neumann, Shannon, Ada Lovelace, Gates... |
| Literatura & Humanidades | Voltaire, Montaigne, Harari, Pinker... |

## Board Personalizado

Edite `advisors/board.json` → campo `custom_board.members` para montar seu board pessoal.

## Modo Squad

Para análises profundas, cada conselheiro responde da sua perspectiva única,
seguido de uma síntese do board com convergências e divergências.
