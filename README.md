## Premissa Central

> **Começar pelo fluxo que gera dinheiro.**
>
> Inteligência de Mercado → Diagnóstico → Comercial → Proposta → Entrega → Conteúdo → Tráfego → Pós-venda

Conteúdo é produção. Diagnóstico, venda e pós-venda são **crescimento**.
