# Checklist Semanal — Produção de Conteúdo com IA

> Imprima ou salve no seu celular.
> Uma linha por ação. Risco quando feito.

---

## TODO MÊS (dia 1 ou 2 do mês)

```
[ ] Abrir o Projeto do cliente no Claude
[ ] Preencher o Prompt 1 (calendário mensal) com as infos do mês
[ ] Revisar o calendário gerado
[ ] Ajustar o que não faz sentido
[ ] Salvar o calendário no Notion / Drive / onde preferir
[ ] Repetir para cada cliente ativo
```

Tempo estimado: 20 min por cliente

---

## TODO COMEÇO DE SEMANA (segunda ou terça)

```
[ ] Abrir o Projeto do cliente no Claude
[ ] Olhar o calendário do mês — ver quais posts são desta semana
[ ] Preencher o Prompt 2 (pautas) com os temas da semana
[ ] Revisar os ganchos e ângulos que o Claude entregou
[ ] Aprovar ou ajustar os ângulos
[ ] Preencher o Prompt 3 (legendas + criativo) com base nas pautas aprovadas
[ ] Revisar cada legenda

CRIATIVO — para cada post, escolher uma opção:
[ ] Tem designer? → Enviar o Briefing para Designer (entregável A)
[ ] Sem designer? → Colar o Prompt GPT no ChatGPT e gerar imagem (entregável B)
[ ] Tem foto própria? → Montar manualmente no Canva (ignorar A e B)
[ ] É vídeo? → Usar as Orientações para Vídeo como roteiro (entregável C)

[ ] Copiar legenda + hashtags
[ ] Abrir o agendador (Meta Business Suite / Buffer / Later)
[ ] Agendar cada post com imagem + horário
[ ] (Turista FC) Rodar Prompt 4 — gerar versão white label de cada post
[ ] (Turista FC) Enviar white label no grupo de WhatsApp das agências
[ ] Repetir para cada cliente ativo
```

Tempo estimado: 40 min por cliente (45 min para o Turista FC)

---

## QUANDO UM POST NÃO FUNCIONAR

```
[ ] Anote o que não funcionou (tema, formato, horário)
[ ] No próximo planejamento mensal, inclua no campo "o que não funcionou"
[ ] Peça ao Claude para sugerir o que ajustar
```

---

## QUANDO ALGO MUDAR NO CLIENTE

```
[ ] Vá até o Projeto do cliente no Claude
[ ] Clique em "Project Instructions"
[ ] Adicione ou ajuste a informação que mudou
[ ] Salve
[ ] Teste com: "O que mudou nesse cliente? Me confirme."
```

---

## SETUP INICIAL (só uma vez por cliente)

```
[ ] Criar novo Projeto no Claude (claude.ai → Projects → New Project)
[ ] Nomear: "Conteúdo — [Nome do Cliente]"
[ ] Preencher o template de instruções (Prompt 0)
[ ] Colar nas "Project Instructions"
[ ] Testar com: "Me apresente esse cliente em 5 linhas"
[ ] Ajustar se necessário
```

Tempo estimado: 20 min por cliente

---

## TEMPO TOTAL ESTIMADO POR CLIENTE

| Ação | Frequência | Tempo |
|---|---|---|
| Setup inicial | Uma vez | 20 min |
| Calendário mensal | 1x/mês | 20 min |
| Produção semanal | 4x/mês | 30 min |
| **Total mensal (exceto setup)** | | **~2h por cliente** |

Para 5 clientes: ~10h/mês de trabalho de conteúdo.
Versus o que levaria manualmente: 40–60h/mês.
