# PROMPT 4 — Versão White Label para Agências Parceiras

> Usado após o Prompt 3 (legendas aprovadas).
> Gera uma versão de cada post sem marca Turista FC,
> pronta para as agências copiarem e colarem nos próprios canais.

---

## Quando usar

Depois de aprovar as legendas do Turista FC, rode este prompt
para gerar o material do grupo de WhatsApp com as agências.

---

## O Prompt (copie tudo abaixo da linha)

---

```
Agora crie a versão white label de cada post aprovado.

REGRAS:
- Remove qualquer menção ao nome Turista FC
- A agência parceira é sempre o sujeito ("nossa equipe", "trabalhamos com", "oferecemos")
- Mantém o mesmo tema, ângulo e qualidade do post original
- CTA: "Fale com a nossa equipe" / "Entre em contato" / "Solicite mais informações"
- Tom: a agência fala diretamente para o cliente final dela
- Canal de destino: WhatsApp, Instagram e canais próprios das agências

Para cada post, entregue:
1. VERSÃO WHITE LABEL — legenda completa, pronta para copiar e colar
2. INSTRUÇÃO PARA A AGÊNCIA — uma linha explicando como usar
   (ex: "Poste com foto de jogo / envie no grupo de clientes VIP")

Formato: um post por vez, separado por linha tracejada.
```

---

## Exemplo do que você recebe

**Post original (Turista FC):**
> "O nome que aparece no ingresso é o seu. Não o de uma plataforma,
> não o de um intermediário desconhecido. O seu. Isso é procedência
> oficial. É o que o Turista FC garante há 16 anos."
> CTA: "Fale com um consultor"

**Versão white label (para a agência):**
> "O nome que aparece no ingresso é o do seu cliente. Não o de uma
> plataforma, não o de um intermediário. O dele. É assim que
> trabalhamos: com procedência oficial e rastreabilidade total em
> cada experiência que oferecemos."
> CTA: "Entre em contato com nossa equipe"

> **Instrução para a agência:** Poste no feed ou envie no grupo
> de clientes interessados em experiências esportivas internacionais.

---

## Dica para distribuição no WhatsApp

Quando for enviar para o grupo das agências, use este formato:

```
Oi [nome] / Oi pessoal,

Segue material desta semana pronto para usar nos seus canais.
Só copiar, colar e adaptar o CTA com o seu contato.

---
[colar versão white label do post 1]
---
[colar versão white label do post 2]
---
[colar versão white label do post 3]
---

Qualquer dúvida, estamos aqui.
[assinatura Turista FC]
```
