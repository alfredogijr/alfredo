# PROMPT 2 — Pautas da Semana (Antes de Escrever)

> Use este prompt UMA VEZ POR SEMANA, dentro do Projeto do cliente.
> Antes de pedir as legendas, você aprova as pautas.
> Isso evita reescrever tudo depois se o ângulo estiver errado.

---

## Por que este passo existe?

Aprovar a pauta antes de escrever economiza tempo.
Se o ângulo estiver errado, você corrige em 30 segundos.
Se você pedir a legenda direto e não gostar, vai reescrever muito mais.

---

## O Prompt (copie tudo abaixo da linha)

---

```
Vamos produzir os posts desta semana.

POSTS DA SEMANA (do calendário que fizemos):
Post 1: [tema]
Post 2: [tema]
Post 3: [tema]

Para cada post, antes de escrever, me entregue:
- Gancho: a primeira frase que vai parar o scroll
- Ângulo: qual aspecto específico vamos explorar (não genérico)
- Referência ou dado: algum fato, situação real ou exemplo concreto que embase
- Por que vai funcionar para nossa audiência: em 1 linha

Aguarde minha aprovação antes de escrever as legendas.
```

---

## O que você faz ao receber as pautas

Leia cada uma e responda uma de três formas:

**Se aprovou tudo:**
```
Aprovado. Pode escrever todas as legendas.
```

**Se quer mudar algo:**
```
Post 1: aprovado.
Post 2: troca o ângulo para [o que você quer].
Post 3: aprovado, mas usa o exemplo de [situação específica] em vez do que sugeriu.
Agora escreve os 3.
```

**Se quer mudar o tema:**
```
Post 2 não faz sentido essa semana. Troca por [outro tema].
Refaz a pauta do post 2 e me mostra antes de escrever.
```

---

## Exemplo preenchido:

```
Vamos produzir os posts desta semana.

POSTS DA SEMANA:
Post 1: Como a IA ajudou uma escola a aumentar matrículas
Post 2: 3 ferramentas de IA que qualquer empresa pode usar hoje
Post 3: Bastidores — como montamos um calendário de conteúdo com IA

Para cada post, antes de escrever, me entregue:
- Gancho: a primeira frase que vai parar o scroll
- Ângulo: qual aspecto específico vamos explorar
- Referência ou dado: fato, situação real ou exemplo concreto
- Por que vai funcionar: em 1 linha

Aguarde minha aprovação.
```

---

## Dica

Se um tema estava no calendário mas você não tem o conteúdo necessário
(foto, depoimento, dado), diz antes de pedir a legenda:

```
Post 3 depende de uma foto de bastidores que ainda não tenho.
Troca por um post que não precise de imagem específica.
```

Mais fácil trocar a pauta do que produzir uma imagem de última hora.
