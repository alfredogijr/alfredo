# PROMPT 1 — Calendário Editorial Mensal

> Use este prompt UMA VEZ POR MÊS, dentro do Projeto do cliente no Claude.
> Preencha apenas os campos marcados com [colchetes].
> Tudo mais já está pronto.

---

## Como usar

1. Abra o Projeto do cliente no Claude
2. Copie o prompt abaixo
3. Preencha os [campos entre colchetes]
4. Cole no chat e envie
5. Revise o que o Claude entregar
6. Salve o calendário no seu sistema de preferência

---

## O Prompt (copie tudo abaixo da linha)

---

```
Vamos planejar o conteúdo de [MÊS] de [ANO].

INFORMAÇÕES DO MÊS:
- Objetivo principal deste mês: [ex: aumentar seguidores / promover um serviço específico / gerar leads]
- Datas importantes ou comemorativas: [ex: Dia das Mães, volta às aulas, feriado X, lançamento Y]
- Novidade, promoção ou campanha especial: [ex: desconto de X% até dia 15 / lançamento de novo serviço]
- O que funcionou bem no mês passado: [ex: post de depoimento teve muito alcance / reels cresceram]
- O que não funcionou no mês passado: [ex: posts muito longos engajaram pouco / tema X não repercutiu]
- Frequência de postagem: [ex: 3x por semana no feed + stories diários]

ENTREGUE:
1. Calendário editorial com 12 ideias de post
   Para cada post: tema, pilar de conteúdo, formato sugerido (carrossel / foto / reels / stories), semana
2. Uma campanha ou sequência temática do mês (3 posts conectados)
3. 3 ideias de stories de engajamento (enquete, pergunta, quiz)
4. Sugestão de horários de publicação por plataforma

Organize em formato de tabela quando possível.
Ao final, me diga quais são os 3 posts mais estratégicos do mês e por quê.
```

---

## Exemplo preenchido (para a Grão de Mostarda — junho):

```
Vamos planejar o conteúdo de JUNHO de 2026.

INFORMAÇÕES DO MÊS:
- Objetivo principal: posicionamento como referência em IA para negócios locais
- Datas importantes: Dia dos Namorados (12/06), início do inverno (21/06)
- Novidade ou campanha: lançamento do serviço de Diagnóstico de IA (DiagIA)
- O que funcionou bem: posts com "antes e depois" de clientes
- O que não funcionou: posts muito teóricos sem exemplo prático
- Frequência: 3x no feed + 4x stories por semana

ENTREGUE:
[resto do prompt...]
```

---

## Depois que o Claude entregar

Faça apenas 3 perguntas para si mesmo ao revisar:

1. **Faz sentido para este cliente?** (nada genérico demais)
2. **Cobre os objetivos do mês?** (produto a lançar, data importante, etc.)
3. **Tenho como produzir esse conteúdo?** (imagens, vídeos, depoimentos disponíveis)

Se algo não funcionar, diz pro Claude:
- "Troca o post X por um sobre [outro tema]"
- "Essa semana prefiro focar em [assunto]"
- "Remove os reels — não temos capacidade de produzir vídeo esse mês"

Quando estiver bom: salva e vai para o Prompt 2.
